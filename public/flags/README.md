# Flag assets

This directory contains the local SVG flag images displayed by Are Flags Lowered.

- U.S. state, District of Columbia, and territory flags: https://github.com/nibsbin/us-state-flags-svg (the source collection identifies them as public-domain images).
- U.S. national flag: https://github.com/lipis/flag-icons (MIT licensed).

Each file is named for the existing lowercase selector code (for example, `va.svg` and `pr.svg`).
